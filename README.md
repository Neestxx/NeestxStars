<h2>
  <u>Возможности:</u>
  <br>
  <b>1.</b>автоматическая продажа Telegram звезд<br>
  <b>2.</b>Создание промокодов<br>
  <b>3.</b>Создание рассылки пользователям (также возможна рассылка с картинкой)<br>
  <b>4.</b>Возможность оплаты как рублями, так и криптовалютой<br>
</h2>

<br>
<h2>
  <b>Установка:</b>
  <br>
  <b>1.</b><i>Клонируйте репозиторий:</i> <code>bash
   git clone https://github.com/Neestxx/NestVPN.git</code>
  <br>
  <br>
  <b>2.</b><i>Установите зависимости:</i> <code>pip install -r requirements.txt</code>
  <br>
  <br>
  <b>3.</b><i>Настройте переменные окружения в файле <code>.env</code> в корне проекта и заполните его</i>
  <br>
  <br>
  <b>4.</b><i>Запустите бота: <code>python main.py</code></i>
  <br>
  <br>
